How Prediction Works

Theory
1
Extract Context
The last 2 words from your input become the Markov context (w₁, w₂).
2
Trigram Lookup
Find all words w₃ seen after (w₁, w₂) in training. Compute P(w₃|w₁,w₂) using Laplace smoothing.
3
Backoff if Sparse
If no trigram found → try bigram P(w₃|w₂) → else use unigram P(w₃).
4
Return Top 3
Sort all candidates by probability. Return rank 1, 2, 3.
